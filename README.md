# java-lotto-precourse
## 🧱 구현 기능 목록

### 로또 발행 기능
- [ ] 구입 금액 입력 및 예외 처리
- [ ] 구입 금액에 따른 로또 장 수 계산
- [x] 1~45 사이의 번호 유효성 검증 (`LottoNumber`)
- [x] 6개 번호 유효성 검증 및 중복 검사 (`Lotto`)
- [ ] 1~45 사이의 6개 숫자 랜덤 생성 (`LottoGenerator`)
- [ ] 중복 없는 번호 검증 및 오름차순 정렬
- [ ] 발행된 로또 번호 출력

### 당첨 번호 입력 기능
- [ ] 당첨 번호 입력 (쉼표 기준 분리)
- [ ] 보너스 번호 입력
- [ ] 입력값 유효성 검증 (1~45, 중복 불가)

### 당첨 결과 계산 기능
- [ ] 각 로또의 당첨 번호 개수 계산
- [ ] 보너스 번호 일치 여부 판단
- [ ] Rank Enum을 통해 등수 및 상금 매핑

### 수익률 계산 기능
- [ ] 총 상금 / 총 구입 금액 × 100
- [ ] 소수 둘째 자리 반올림 처리
- [ ] “총 수익률은 XX.X%입니다.” 출력

### 예외 처리
- [ ] 금액/번호/보너스 입력 오류 시 예외 발생
- [ ] `[ERROR]`로 시작하는 메시지 출력 및 재입력 요청
